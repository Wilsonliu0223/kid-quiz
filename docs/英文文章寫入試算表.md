# 英文文章寫入 Google 試算表（方案 A）

產文後可由本機腳本（或 Cursor）呼叫 **同一個 Apps Script 網址**，自動寫入工作表 **`英文文章`**。  
寫入需 **token**，避免外人亂貼文章。

相關程式：`docs/google-apps-script.gs`  
上傳腳本：`tools/upload-en-articles.mjs`

你的試算表：  
https://docs.google.com/spreadsheets/d/1CIkz0vH-Dp3xj9K3OUvXO_mfaFwq2-qzEJbQcIyWvPg/edit

## 一、更新 Apps Script（必做）

1. 試算表 → **擴充功能** → **Apps Script**
2. 用本專案 `docs/google-apps-script.gs` **全文覆蓋**後儲存
3. **部署** → **管理部署作業** → 鉛筆 → 版本選 **新版本** → 部署  
   （網址可與成績同一個 `SCORE_LOG_URL`，不必換）

---

## 二、設定寫入密碼（token）

1. Apps Script 左側 **專案設定**（齒輪）
2. 下方 **指令碼屬性** → **新增指令碼屬性**
3. 新增：

| 屬性 | 值（自己想一串，勿公開） |
|------|--------------------------|
| `EN_ARTICLE_WRITE_TOKEN` | 例如 `kq-en-寫一串亂數` |

4. 本機建立檔案（**勿 commit**）：

路徑：`.local/en-article-secrets.env`

```env
SCORE_LOG_URL=https://script.google.com/macros/s/你的部署/exec
EN_ARTICLE_WRITE_TOKEN=與上面完全相同的字串
```

可複製範本：`.local/en-article-secrets.env.example`

## 三、本機上傳（產文後）

### 1. 準備 JSON（一天 5 則）

```json
{
  "date": "2026-08-26",
  "replace": true,
  "rows": [
    {
      "date": "2026-08-26",
      "seq": 1,
      "category": "sport",
      "topic_key": "mlb-example",
      "title": "Example title",
      "body_l1": "...",
      "body_l2": "...",
      "body_l3": "...",
      "vocab": [{ "word": "title", "gloss": "A prize for winning.", "example": "He won the title." }],
      "quiz": [
        {
          "type": "comp",
          "q": "What did the team win?",
          "options": ["The title", "A school bus", "A pizza", "A phone"],
          "answer": "The title"
        },
        {
          "type": "comp",
          "q": "Where was the game?",
          "options": ["New York", "The moon", "Under the sea", "A library"],
          "answer": "New York"
        },
        {
          "type": "comp",
          "q": "Why was the win important?",
          "options": ["It was the final", "It was raining", "Nobody watched", "The team lost"],
          "answer": "It was the final"
        },
        {
          "type": "vocab",
          "q": "A prize for winning.",
          "options": ["title", "stadium", "rocket", "sensor"],
          "answer": "title"
        },
        {
          "type": "vocab",
          "q": "A large place where people watch sports.",
          "options": ["stadium", "title", "band", "diabetes"],
          "answer": "stadium"
        }
      ],
      "source_title": "...",
      "source_url": "https://...",
      "status": "draft",
      "note": ""
    }
  ]
}
```

- `title` 是給孩子看的自然英文標題，請先做文法與語意檢查，不要為了像新聞標題而省略必要的冠詞、介系詞或受詞（例如 `drink water`）。避免把天氣、建築等無生命主詞寫成會「要求」人的動詞；若原句讀起來不像母語者會說的話，請改寫後再上傳。  
- `source_title` 才是新聞來源的原始標題；網站顯示的 `title` 可以是根據新聞內容改寫的兒童版，不要直接把來源標題當成已通過檢查的英文。
- `quiz`：固定 **5 題**（建議 3 理解 `comp` + 2 單字 `vocab`），全英文；網站可 Prev／Next 回頭改，送出才計分  
- `dialogue`：情境對話（與該則同一列）。結構：

```json
{
  "scene": "Outside the stadium before the game.",
  "roles": ["Reporter", "Fan"],
  "turns": [
    {
      "speaker": "Reporter",
      "l1": "Are you here for the big game?",
      "l2": "Are you here to watch the La Liga match?",
      "l3": "Are you here to watch Barcelona and Athletic Club?",
      "focus": ["stadium"]
    }
  ],
  "quiz": [
    {
      "type": "comp",
      "q": "Where are they talking?",
      "options": ["Outside the stadium", "On the moon", "In a library", "At a hospital"],
      "answer": "Outside the stadium"
    }
  ]
}
```

對話小測建議 **3 題**（可回頭改）。上傳後請確認 Apps Script 版本含 `dialogue_json`（`EN_ARTICLE_API_VERSION` 至少 `2026-08-27-dialogue-v1`）。  
- `replace: true` → 先刪該日舊列再寫入（覆蓋今日）  
- `replace: false` 或不寫 → 只 append（可能重複）

本機每天 07:30 自動產文：`tools/run-daily-en-articles.bat`（Windows 工作排程 `kid-quiz-daily-en-articles`）。重裝排程執行 `tools/install-daily-en-articles-task.bat`。日誌在 `.local/daily-en-articles.log`。

## 四、API 摘要

同一個 `SCORE_LOG_URL`：

| action | 方法 | 說明 |
|--------|------|------|
| `appendEnArticles` | POST | 附加列；需 `token` + `rows` |
| `replaceEnArticlesForDate` | POST | 刪該日後再寫；需 `token` + `date` + `rows` |
| `listEnArticles` | GET/POST | 列近期／某日摘要；需 `token` |

POST body 範例：

```json
{
  "action": "replaceEnArticlesForDate",
  "token": "你的 token",
  "date": "2026-08-26",
  "rows": [ /* 同上 */ ]
}
```

## 五、早上產文流程（給 Cursor）

1. 你說：「產今日英文文章」
2. 我執行 `list` 看近 7 天主題，避開重複（例如連續網球）
3. 上網產 5 則 L1/L2/L3 → 存 JSON
4. 跑 `upload-en-articles.mjs`（`replace: true`）寫入「英文文章」
5. 你到表裡把 **狀態** 改成 `published`（或產文時直接寫 published）

## 常見問題

**Q：回傳 unauthorized？**  
A：Script Properties 的 token 與 `.local/en-article-secrets.env` 不一致，或還沒「新版本」部署。

**Q：回傳尚未設定 EN_ARTICLE_WRITE_TOKEN？**  
A：還沒在 Apps Script 專案設定加指令碼屬性。

**Q：token 可以放 config.site.js 嗎？**  
A：**不要**。那是公開 GitHub；只放 `.local/`（已 gitignore）。
