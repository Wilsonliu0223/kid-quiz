# 英文文章寫入 Google 試算表（方案 A）

產文後可由本機腳本（或 Cursor）呼叫 **同一個 Apps Script 網址**，自動寫入工作表 **`英文文章`**。  
寫入需 **token**，避免外人亂貼文章。

相關程式：`docs/google-apps-script.gs`  
上傳腳本：`tools/upload-en-articles.mjs`

你的試算表：  
https://docs.google.com/spreadsheets/d/1CIkz0vH-Dp3xj9K3OUvXO_mfaFwq2-qzEJbQcIyWvPg/edit

---

## 一、更新 Apps Script（必做）

1. 試算表 → **擴充功能** → **Apps Script**
2. 用本專案 `docs/google-apps-script.gs` **全文覆蓋**後儲存
3. **部署** → **管理部署作業** → 鉛筆 → 版本選 **新版本** → 部署  
   （網址可與成績同一個 `SCORE_LOG_URL`，不必換）

---

## 二、設定寫入密碼（token）

1. Apps Script 左側 **專案設定**（齒輪）
2. 下方 **指令碼屬性** → **新增指令碼屬性**
3. 新增：

| 屬性 | 值（自己想一串，勿公開） |
|------|--------------------------|
| `EN_ARTICLE_WRITE_TOKEN` | 例如 `kq-en-寫一串亂數` |

4. 本機建立檔案（**勿 commit**）：

路徑：`.local/en-article-secrets.env`

```env
SCORE_LOG_URL=https://script.google.com/macros/s/你的部署/exec
EN_ARTICLE_WRITE_TOKEN=與上面完全相同的字串
```

可複製範本：`.local/en-article-secrets.env.example`

## 三、本機上傳（產文後）

### 1. 準備 JSON（一天 5 則）

```json
{
  "date": "2026-08-26",
  "replace": true,
  "rows": [
    {
      "date": "2026-08-26",
      "seq": 1,
      "category": "sport",
      "topic_key": "mlb-example",
      "title": "Example title",
      "body_l1": "...",
      "body_l2": "...",
      "body_l3": "...",
      "vocab": [{ "word": "title", "gloss": "A prize for winning.", "example": "He won the title." }],
      "source_title": "...",
      "source_url": "https://...",
      "status": "draft",
      "note": ""
    }
  ]
}
```

- `replace: true` → 先刪該日舊列再寫入（覆蓋今日）  
- `replace: false` 或不寫 → 只 append（可能重複）

### 2. 執行

```powershell
cd c:\Users\Wilson\Projects\kid-quiz
node tools/upload-en-articles.mjs path\to\articles.json
```

成功會印 `ok: true`、`appended: 5`。

### 3. 查近幾天（去重用）

```powershell
node tools/upload-en-articles.mjs --list --days 7
node tools/upload-en-articles.mjs --list --date 2026-08-26
```

## 四、API 摘要

同一個 `SCORE_LOG_URL`：

| action | 方法 | 說明 |
|--------|------|------|
| `appendEnArticles` | POST | 附加列；需 `token` + `rows` |
| `replaceEnArticlesForDate` | POST | 刪該日後再寫；需 `token` + `date` + `rows` |
| `listEnArticles` | GET/POST | 列近期／某日摘要；需 `token` |

POST body 範例：

```json
{
  "action": "replaceEnArticlesForDate",
  "token": "你的 token",
  "date": "2026-08-26",
  "rows": [ /* 同上 */ ]
}
```

## 五、早上產文流程（給 Cursor）

1. 你說：「產今日英文文章」
2. 我執行 `list` 看近 7 天主題，避開重複（例如連續網球）
3. 上網產 5 則 L1/L2/L3 → 存 JSON
4. 跑 `upload-en-articles.mjs`（`replace: true`）寫入「英文文章」
5. 你到表裡把 **狀態** 改成 `published`（或產文時直接寫 published）

## 常見問題

**Q：回傳 unauthorized？**  
A：Script Properties 的 token 與 `.local/en-article-secrets.env` 不一致，或還沒「新版本」部署。

**Q：回傳尚未設定 EN_ARTICLE_WRITE_TOKEN？**  
A：還沒在 Apps Script 專案設定加指令碼屬性。

**Q：token 可以放 config.site.js 嗎？**  
A：**不要**。那是公開 GitHub；只放 `.local/`（已 gitignore）。
