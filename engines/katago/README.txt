KataGo browser engine for kid-quiz
=================================

- Worker bundle derived from Sir-Teo/web-katrain (MIT):
  https://github.com/Sir-Teo/web-katrain
- Upstream KataGo (MIT):
  https://github.com/lightvector/KataGo
- Network file models/katago-small.bin.gz is the official test net
  g170-b6c96-s175395328-d26788732 (CC0 / see katagotraining.org network license).
- TensorFlow.js WASM binaries under tfjs/ are from @tensorflow/tfjs-backend-wasm.

Strength note shown in the app:
  KataGo small net b6c96 + search ≈ strong amateur dan to low-pro strength
  depending on device; not the largest desktop KataGo networks.
